# 🏛️ 3D Renaissance Portfolio

An interactive 3D Renaissance parallax portfolio and digital exhibition built with **React**, **TypeScript**, **Three.js**, and custom **GLSL shaders**.

🔗 **Live Demo:** [3d-renaissance-portfolio.vercel.app](https://3d-renaissance-portfolio.vercel.app/)

---

## ✨ Features

* **Interactive 3D Exhibition:** Navigate through curated Renaissance-inspired artwork and environments in real-time 3D space.
* **Depth & Parallax Effects:** Smooth camera movement and multi-layered parallax responsiveness driven by cursor and scroll interactions.
* **Custom GLSL Shaders:** Bespoke vertex and fragment shaders for atmospheric lighting, depth-of-field, and surface textures.
* **Responsive Performance:** Optimized asset loading and rendering pipeline powered by Vite and TypeScript.

---

## 🛠️ Tech Stack

* **Framework:** [React](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/)
* **3D Engine:** [Three.js](https://threejs.org/)
* **Graphics & Shaders:** WebGL / Custom GLSL
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Package Manager:** [Bun](https://bun.sh/) / npm
